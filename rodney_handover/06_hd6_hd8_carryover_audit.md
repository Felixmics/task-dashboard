# HD to HD9 feature carry-over audit

**Date:** 21 November 2026, Australia/Brisbane (UTC+10). Written after a read-only inspection of the map files and the project library. Nothing was deleted or edited except this new file.

**Purpose:** Mick asked for confirmation that HD9 is not repeating the old mistake of leaving the best parts of earlier maps behind. This audit lists features from every previous version and from the library apps, how each version does them, which version is best to import, whether HD9 v01 already has them, and a recommendation.

**Standing rule for recommendations:** RODNEY is an AI fishing planner assistant, not a fisheries inspector or a lawyer. Compliance calendar checks, heavy closure labelling, and long legal zoning essays are not recommended for carry-over. Light zone reference (so a skipper can see green water) and light weather/tide advice stay in, because they help plan the trip.

## How to read the table

- **Best to import** is the version whose method or data should be brought into HD9. Often that means the method from one map applied to HD9's better 10 m LAT grid, not a literal copy of older GBR30 tiles.
- **In HD9 v01** is yes / no / partial, with a short evidence string from the v01 HTML, sidecar, or `marks_layer.js`.
- **Recommendation:** carry over / already in / drop, with a reason.
